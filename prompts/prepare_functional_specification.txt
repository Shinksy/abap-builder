- Make processing variables explicit when present in the source.
- Make callable objects explicit when present in the source, including function modules, class methods, instance methods, parameters, and returned values when stated.
- Do not invent missing business logic.
- Do not invent SAP objects, DDIC table names, DDIC field names, callable names, parameters, forms, variable names, or output fields.
- If the source implies a requirement but does not name the SAP object or field, preserve the requirement in plain business terms and mark the technical name as not specified.
- If a section has no source-backed content, omit that section.
- Keep uncertainty from the source visible instead of resolving it by guessing.
